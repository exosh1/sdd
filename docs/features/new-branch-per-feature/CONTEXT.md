# Domain Context — new-branch-per-feature

## Glossary

- Plugin user — a person who runs SDD skills through an AI coding host. NOT Plugin maintainer (the person who develops or publishes the plugin).
- Active feature — a feature explicitly selected as active in the project's local state; it remains active until the user changes that selection. NOT the feature whose branch is currently checked out.
